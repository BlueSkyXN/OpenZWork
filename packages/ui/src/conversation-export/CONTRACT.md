# 对话 Markdown 导出

输入是点击时捕获的目标所提供的只读 V4 行分页函数，输出是完整有效分支的可见用户/助手 Markdown。调用方负责既有服务路由、标题/角色翻译和剪贴板能力；本模块不访问服务定位器、数据库或 DOM。

分页校验 logEpoch、结构 revision 和严格递减游标，完成后复验版本。正文 delta 可继续，结构变化最多整体重试一次；其他读取失败直接返回错误。任何失败都不产生部分成功结果。菜单卸载不终止已发起复制；较晚复制意图是剪贴板写入资格的唯一 owner，较早结果返回 superseded。

模块不写会话、归属或运行状态。正文不进入日志。Markdown 范围、上游接入点与验收见 docs/spec/conversation-controls.md。
