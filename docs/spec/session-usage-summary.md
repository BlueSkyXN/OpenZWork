# 会话累计用量展示（诉求 10 / E6 首个切片）

状态：实现与定向自动化检查已完成；隔离浏览器验证范围见文末。真实产品端到端验收未做。只交付主对话累计 token 的只读展示，不代表账户额度、费用统计或 E6 全部完成。

## 范围与产品规则

- 在现有聊天工具栏的上下文用量面板中增加「本会话累计」：输入、输出、缓存读取、缓存写入和总 token。
- 唯一来源为现有 V4 `SessionUsageState.cumulative`；其生产者 `ProductProjection` 累加主对话 `ModelComplete`，客户端不从消息、工具结果或请求次数推算。不把标题生成、压缩、子代理等后台请求混入本面板口径，不替代 App Usage 的跨会话统计。
- 总 token = 输入 + 输出。AI SDK 已将缓存 token 计入输入，缓存读/写只作明细展示，不再次加到总量。
- 用明确文案区分「累计消耗」与「上下文容量」，说明累计值不是服务商的剩余额度；不展示没有可靠数据来源的费用、账户余额或预算进度。
- 已有上下文容量合法时保留原圆环、占比及来源明细。上下文容量未知但已有累计用量时，仍可查看累计值，触发器使用中性统计图标，不虚构 `0 / 1` 等容量信息。
- 有效的累计零值按 0 展示；没有累计字段或包含负数、非整数、非有限值等非法计数时不展示累计区，不能伪装为零。无上下文且累计全部为零时不新增空触发器（草稿/初始会话）。
- 完整数字按当前语言格式化；桌面 hover/键盘 focus 与手机 touch 使用同一面板和同一数值口径，适配窄屏与长数字。

## 所有者、接口与事件顺序

```text
CLI ProductProjection（累计用量事实的唯一所有者）
  → V4 snapshot / state.updated.usage（完整累计值，而非增量计数）
      ├─ desktop-continuous：连续帧
      └─ web-remote-replayable：快照 / 衔接后的增量 / 断档恢复
  → ConversationProjectionStore（既有身份、水位和整体替换规则）
  → V4ComposerModelControls（只读 usage）
  → ChatContextUsage（上下文面板 + 累计用量区）
```

- 不新增 Zustand 状态、持久化、RPC、定时器或网络查询。UI 只增加可选累计 props 和纯展示模型；展开状态仍由现有面板本地持有。
- `state.updated.usage`、重连快照、会话切换均整体替换用量，UI 不做累计相加、不保留上一会话数字、不用最大值掩盖服务端重置。
- owner/lease、workspaceIdentity、seq/epoch/stale 防护、两种交付语义完全沿用现有会话订阅链；本切片不改变 admission 或重连行为。
- 历史累计值能否恢复取决于 CLI 的既有投影与持久化能力；本切片只展示服务端提供的当前累计事实，不宣称修复所有历史数据缺项。

## 非目标与迁移边界

- 不恢复官方账号、套餐、在线额度端点、云遥测或旧数据读取。
- 不添加服务商余额查询、价格表、费用估算、预算限制、超额自动停止、30 天保留期调整或统计新维度。
- 不修改既有共享用量协议，不迁移数据库，不向旧 `TaskUsageState` 建立第二份累计状态。
- 额度一词的产品含义尚未确认；本切片依据已记录的「会话内累计 token 展示」诉求推进，不能据此宣称用户选择了其他额度功能。

## 验收场景

| 场景                                                     | 断言                                                   |
| -------------------------------------------------------- | ------------------------------------------------------ |
| 输入 1,000、输出 200、缓存读 600、写 100                 | 总量为 1,200，非 1,900；四个明细各自准确               |
| 累计为零 / 字段缺失 / 非法计数                           | 零可显示，缺失与非法不伪装为零                         |
| 上下文未知、累计有值                                     | 统计触发器可展开累计区，不显示容量百分比               |
| 连续 `state.updated`、重复完整累计值、恢复快照、切换会话 | 数值随权威值替换，不叠加、不串会话；客户端不产生新事实 |
| 桌面 hover / 键盘 focus                                  | 展开原面板，可读累计区；退出后按现有浮层语义关闭       |
| 手机触摸 / 窄屏                                          | 可打开同一面板；无横向溢出；主要数据不隐藏             |
| 中文/英文、浅色/深色                                     | 标题、明细、统计口径文案正确，数字本地化且可读         |
| 数据更新                                                 | 已展开时更新总数，累计区不发起网络请求                 |

验证分层：Node 单测覆盖纯展示模型、协议替换语义与组件静态渲染；隔离浏览器 fixture 挂载真实工具栏用量组件验证浮层交互与响应式。fixture 不启动真实模型或 Electron，不等同完整应用端到端验收。
