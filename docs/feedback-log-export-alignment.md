# 反馈诊断日志上传边界





日期范围按归档开始时的本地时区计算，以文件最后修改时间筛选 `[当天 00:00，次日 00:00)`，不使用滚动 24 小时；跨年及夏令时仍按自然日处理。文件打开后再次检查修改时间。此规则是文件筛选，持续追加的文件可能包含更早的记录，不按每行时间戳切分。本地手动导出日志的日期范围保持原有契约。

正在追加的日志按打开后 `fstat` 确定的字节数进行有界读取，本次读取期间新增的尾部留待下一次归档，不因良性追加丢弃整个文件。提前读到 EOF 的文件跳过；读取结果仍经过编码检查和完整脱敏，不能原文上传。`about.txt` 记录已收集文件数，以及日志候选文件被跳过的数量和原因分类，不额外记录被跳过文件的名称或路径。

脱敏策略覆盖嵌套 JSON、正文/消息/工具输入输出字段、常见凭证、URL 凭证、私钥和用户目录。正则不能保证识别任意自然语言隐私，日志默认勾选，表单保留范围和残留业务信息提示，用户可在提交前取消勾选；截图需用户主动添加和检查。

URL 路径也可能携带凭据。诊断文本中的 URL 仅保留协议、主机和端口，非空路径统一替换为 `[REDACTED]`；仍移除 userinfo、query 和 fragment。用户正文保留普通排障链接的路径，但 webhook、重置、邀请、回调、下载、验证及令牌路径，以及带认证/签名参数的链接，隐藏整个路径；路径判定包含百分号编码形式，无法解码时保守隐藏。此规则统一用于工单标题、描述、补充评论和诊断 ZIP，不修改用户主动填写的联系方式。验收需在 shared 文本输出、full/compact ZIP 的全部 entry，以及 create/comment 请求体三层确认路径型模拟凭据没有残留，并确认普通正文链接仍可用于定位问题。
